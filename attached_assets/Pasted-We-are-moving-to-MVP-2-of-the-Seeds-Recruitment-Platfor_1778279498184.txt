We are moving to MVP 2 of the Seeds Recruitment Platform.

MVP 1 already includes:
- Public website
- Application form
- Application database
- Admin login
- Admin application list
- Application detail page
- Status update
- Admin note
- CSV export

MVP 2 goal:
Build the selection management module.

The goal is to support the selection process after applications are submitted:
1. Evaluator accounts
2. Evaluator assignment
3. Document review evaluation
4. Interview management
5. Interview evaluation
6. Final decision management
7. Decision change logs
8. Admin and evaluator role-based access control

Important:
Do not remove or break any MVP 1 features.
Keep all existing application data.
Add database migrations safely.
After implementation, run regression tests for MVP 1 flows.

Required roles:
- admin
- evaluator

Admin capabilities:
- View all applications
- Create, edit, and deactivate evaluator accounts
- Assign evaluators to applications
- View evaluation completion status
- View evaluation scores and comments
- Select applicants for interview
- Create and edit interview schedule information
- View interview evaluation results
- Set final decision:
  - pending
  - accepted
  - rejected
  - waitlisted
  - withdrawn
- Write decision reason
- View decision change logs

Evaluator capabilities:
- Login as evaluator
- View only applications assigned to them
- Open assigned application detail
- Read submitted application content
- Submit document review evaluation
- Submit interview evaluation if assigned
- Edit their own evaluation
- Cannot view other evaluators’ evaluations
- Cannot change application status
- Cannot set final decision
- Cannot access admin-only pages
