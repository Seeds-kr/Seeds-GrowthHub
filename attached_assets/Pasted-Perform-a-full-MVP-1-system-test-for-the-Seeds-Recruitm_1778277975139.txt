Perform a full MVP 1 system test for the Seeds Recruitment Platform.

This is not only a code review. You must actually run the app, test the user flows, identify bugs, fix them, and rerun the tests until the MVP 1 acceptance criteria pass.

MVP 1 scope:
1. Public website
2. Recruitment information
3. Application form submission
4. Admin login
5. Admin application management
6. Status update
7. Admin note saving
8. CSV export

Use the following testing approach:

1. Inspect the current app structure.
2. Check that the app can install dependencies and run without errors.
3. Check that database schema and migrations work.
4. Create automated E2E tests using Playwright if possible.
5. Run the tests.
6. Fix any issues found.
7. Rerun the tests.
8. Produce a final test report.

Important:
- Do not delete existing non-test data.
- Use test data with the prefix “[E2E_TEST]”.
- Clean up only the test data created by this test run.
- Do not expose admin credentials to the client.
- Do not hardcode real secrets in source code.
- Use environment variables for admin credentials.
- If browser automation is not available in this Replit environment, explain the limitation and perform the closest possible automated and manual verification.

Test environment:
- Use ADMIN_EMAIL=admin@test.local
- Use ADMIN_PASSWORD=TestPassword123!
- Confirm that these are read from environment variables.
- Confirm that admin routes are protected.

Required test scenarios:

A. Public site smoke test
- / loads successfully

- /apply loads successfully

- Footer is visible

E. Admin application list
- Application list loads

- Status badges display correctly

- Detail page loads for a submitted application

G. CSV export
- CSV export button exists

- Admin credentials are not present in client-side code
