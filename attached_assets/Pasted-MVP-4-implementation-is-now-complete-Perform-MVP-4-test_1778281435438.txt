MVP 4 system test checklist:

A. Activity records
- Admin can create activity record for student
- Activity record appears in admin student timeline
- Student-visible record appears in student timeline
- Admin-only record does not appear in student timeline
- Activity record can link to source if implemented

B. Project records
- Admin can create project
- Admin can assign student to project
- Student can view own project
- Student cannot view another student’s private project
- Admin can update project status
- Project appears in student report

C. Artifacts
- Admin can add artifact to student or project
- Artifact appears in admin view
- Student-visible artifact appears in student view
- Admin-only artifact does not appear in student view
- Student cannot access other students’ private artifacts by changing URL/API ID

D. Feedback
- Admin can create feedback for student/project/submission/activity record
- Student-visible feedback appears to student
- Admin-only feedback is hidden from student
- Feedback appears in admin report
- Feedback visibility rules are enforced by server/API

E. Skill tags
- Admin can create skill tag
- Admin can attach tag to activity record/project/artifact/feedback/student
- Student tag summary appears in admin student report
- Cohort tag summary appears in cohort summary if implemented

F. Student timeline
- Admin can view full student timeline
- Student can view own visible timeline
- Timeline includes relevant activities, projects, artifacts, and feedback
- Filters work if implemented

G. Student activity report
- Admin can view student activity report
- Student can view own report
- Report includes:
  - profile
  - cohort/program
  - attendance summary
  - assignment summary
  - project summary
  - artifacts
  - feedback highlights
  - skill tag summary
  - activity timeline
- Admin-only notes are excluded from student report

H. Cohort activity summary
- Admin can view cohort summary
- Summary includes students, attendance, assignments, projects, artifacts, and tags where implemented
- Summary does not expose private data to unauthorized users

Security and privacy testing:
- Student cannot access another student’s timeline
- Student cannot access another student’s report
- Student cannot access another student’s artifacts
- Student cannot access admin-only feedback
- Student cannot access admin-only activity records
- Evaluator cannot access student records unless explicitly allowed
- Unauthenticated user cannot access student/admin routes
- Private records are not exposed through API responses
- Admin-only notes are never included in student-facing views
