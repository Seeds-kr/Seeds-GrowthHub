# Seeds GrowthHub - 문서 체계 및 용어 표준

## 1. 문서 목적

이 문서는 Seeds GrowthHub 관련 문서들의 기준본, 문서별 책임 범위, 공통 용어를 정의한다. 이후 논의와 구현 지시는 이 문서를 기준으로 문서 간 충돌을 해소한다.

## 5. 공통 용어 표준

### 5.1 Seeds GrowthHub

Seeds의 운영관리와 학생 성장증거 축적을 연결하는 내부 운영·성장 인프라다.

### 5.2 Core 기반 계층

운영 시스템과 성장 시스템이 공유하는 공통 기반이다. Core는 Ops/Growth와 동급의 하위 시스템이라기보다 기반 계층이다.

### 5.3 운영 시스템 / GrowthHub Ops

회의, 작업, 운영 문서, 모집, 행사, 회계, 공지, 운영 대시보드 등 Seeds 운영 실행을 지원하는 시스템이다.

### 5.4 성장 시스템 / GrowthHub Growth

장기적으로 학생 성장 기록과 해석을 지원하는 시스템이다. 현재 문서에서는 최종 성장시스템이 아니라 성장모델 확정 전에도 유지될 가능성이 높은 성장증거 기록 계층만 다룬다.

### 5.5 성장증거 계층

프로젝트, 스터디, 산출물, 피드백, 회고, 활동기록처럼 성장 해석의 원자료가 되는 기록 계층이다.

### 5.6 성장해석 계층

성장모델, 커리큘럼, 운영모델이 정렬된 뒤 성장증거를 해석하는 계층이다. Phase 4에서 반영한다.

### 5.7 Cohort / 기수

학생 모집과 운영의 시간 단위다.

### 5.8 Program

현재 구현상 기수에 종속된 활동/트랙 단위다. 향후 성장모델·커리큘럼 정렬 과정에서 Curriculum Module, Track, Program 중 어떤 개념으로 재정의할지 검토한다.

### 5.9 Curriculum Module

향후 커리큘럼 정렬 이후 정의할 수 있는 학습/활동 모듈이다. 현재 구현의 programs와 동일하다고 단정하지 않는다.

### 5.10 Project

현재 구현된 프로젝트 객체다. 학생 팀의 산출물, 피드백, 활동기록과 연결된다.

### 5.11 Project Team

별도 테이블이 아니라 Project와 Project Members의 조합을 운영상 부르는 표현이다.

### 5.12 Team

장기적으로 별도 객체가 필요한지 검토할 후보 개념이다. 현재 구현에서는 확정 테이블이 아니다.

### 5.13 Admin

시스템 권한 role이다. Seeds 조직상 운영진 전체를 의미하지 않는다.

### 5.14 운영진

Seeds 조직 역할이다. Program Lead, Ops Manager, Finance/Admin Lead 등 세부 역할을 포함한다. 시스템상으로는 admin, extra_roles 또는 장기적으로 role_assignments로 표현할 수 있다.

### 5.15 Evaluation Surface

평가자는 별도 role이 아니라 admin 또는 mentor가 배정받은 평가 업무를 수행하는 접근 제어 surface다.

### 5.16 Session / Event

Session은 현재 구현된 일정/모임 테이블이다. Event는 정기모임, OT, 발표회, 워크숍 등을 포괄하는 장기 상위 개념이다. 전환기 문서에서는 Events/Sessions로 병기한다.

### 5.17 Source of Truth

특정 데이터나 파일의 원본 위치를 의미한다. GrowthHub는 모든 외부 도구를 대체하지 않고, 필요한 경우 외부 도구를 source of truth로 인정하면서 메타데이터와 연결 맥락을 관리한다.

## 6. 충돌 해결 원칙

1. 용어 충돌은 이 문서의 용어 표준을 따른다.
2. 화면 구조 충돌은 IA 문서를 따른다.
3. 데이터 구조 충돌은 ERD 문서를 따른다.
4. 외부 연계 범위 충돌은 외부 도구 연계 설계를 따른다.
5. 운영 기능 충돌은 Ops 문서를 따른다.
6. 성장 기능 충돌은 Growth 문서를 따른다.
7. 구현 순서 충돌은 Roadmap 문서를 따른다.

## 7. 현재 판단

이 문서는 GrowthHub 문서 세트의 기준점이다. 앞으로 새로운 논의나 구현 지시가 생기면 먼저 이 문서의 용어와 문서 책임 범위에 맞춰 배치한다.
