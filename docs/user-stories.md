# 유저 스토리 — 역할별 주행 목록

이 문서는 "화면이 있다"가 아니라 **"그 역할이 실제로 일을 끝낼 수 있다"** 를 확인하기 위한
목록이다. 각 스토리는 한 사람이 한 번에 끝내는 일 하나이고, 마지막 칸은 실제로 주행한
결과다. 주행하지 않은 것은 비워 둔다 — 추측으로 채우지 않는다.

주행 스크립트: `e2e/stories.mjs` (`node stories.mjs` 로 실행, 결과는 표준 출력)

## 역할

| 역할 | 계정 | 들어오는 문 |
|---|---|---|
| 지원자 | 비로그인 | `/` |
| 운영진 | `admin@seeds.local` | `/admin/login` |

## 주행 결과 (2026-08-04)

**24 PASS / 0 FAIL / 0 BLOCK.** 평가위원 축은 계정이 없어 목록에 없다 — 통과로 세지 않는다.

주행하면서 찾은 실제 결함 3건:

1. **공개 지원서의 검증 문구가 영어였다.** 빈 칸을 두고 제출하면 한국인 지원자가
   `String must contain at least 1 character(s)` / `Invalid email` 을 봤다. 이 사이트에서
   가장 중요한 폼이라 "고장 났나" 로 읽히고 그대로 이탈한다. → `lib/zod-ko.ts` 로 한국어화.
2. **없는 자료를 열면 스피너가 영원히 돌았다.** 상세 화면 10개가 전부
   `if (isLoading || !data) return <Spinner/>` 라, 로딩이 끝나도 `data` 가 비어 있으면
   멈추지 않았다. 느린 건지 없는 건지 알 수 없다. → `ResourceMissing` 으로 404 판을 띄운다.
3. **과제 게시 동선이 목록에서 안 보인다.** 새 과제는 `초안` 으로 저장되고 초안인 동안
   학생 화면에 안 나오는데, 게시 컨트롤이 [수정] 다이얼로그 안에만 있다. 기능은 있으나
   운영진이 "냈다" 고 생각하고 넘어가기 쉽다. → 아직 안 고침(개선 항목).

그 외 12건은 주행 스크립트의 결함이었고(Radix 콤보박스를 `<select>` 로 찾음,
`type` 속성 없는 input 을 CSS 로 못 잡음, `+ 새 …` 뒤에 있는 폼을 안 열음,
"담당하지 않는 프로젝트이거나 존재하지 않습니다" 를 차단으로 인식 못 함 등),
제품 결함이 아니었다. 고친 뒤 다시 주행했다.
